# AI 助理形象立繪統一與修正說明 (Sad & Shy 表情修復)

## 1. 修正背景 (Background)
在 AI 助理（萬能助理）的立繪表情系統中，使用者發現：
- **`Sad`（難過 / 沮喪）** 與 **`Shy`（害羞 / 傲嬌）** 的立繪髮型與其餘表情（如 `default`、`happy`、`angry`、`thinking`）存在明顯不一致：
  - **害羞 (`Shy`)**：原先的瀏海為厚重齊平的一刀切平瀏海，且後腦勺散落了大面積披肩長髮（變成半雙馬尾+散披髮）。
  - **難過 (`Sad`)**：背後同樣有一整圈長厚披髮，且眼眸色彩錯誤變成了藍色（預設為翡翠綠色）。

為了保持角色在對話互動與情緒切換時的**視覺連貫性與真實感**，本次重新生成並修復了這兩款表情立繪。

---

## 2. 修正內容與設計規範 (Refinements)

### 2.1 髮型與特徵嚴格統一
- **高雙馬尾 (Twin-tails)**：保留兩側以深藍色蝴蝶結高高束起的銀白雙馬尾，向兩側自然延伸垂墜至腰間。
- **後頸乾淨 (Clean Nape)**：完全移除背部散落披肩的多餘長髮，使雙馬尾造型俐落乾淨。
- **自然碎瀏海 (Soft Bangs)**：恢復前額自然分撮、略顯微弧度的日系輕盈瀏海，修飾臉型。
- **翡翠綠眼眸 (Emerald Green Eyes)**：統一所有表情的瞳孔顏色為清澈明亮的翡翠綠動漫大眼。

### 2.2 表情與姿態細節對比

| 表情名稱 | 修正前問題 | 修正後姿態與特徵 |
| :--- | :--- | :--- |
| **害羞 (`Shy`)** | 厚重平瀏海、背後大片散髮 | 內八膝蓋微屈害羞站姿，雙手靦腆抓著百褶裙擺，臉部泛起嬌羞紅暈，標準雙馬尾與自然瀏海 |
| **難過 (`Sad`)** | 背後厚重披髮、藍色眼睛 | 雙手在胸前交疊微握，低頭楚楚可憐、眼泛淚光的翡翠綠眼眸，表情委屈柔弱，標準雙馬尾 |

## 3. 技術處理流程 (Technical Workflow)

1. **AI 參考生成**：以 `assistant_default.png` 作為核心架構與服裝參考圖，確保身高、校服款式（深藍背心、白襯衫、青綠領帶、白百褶裙、黑過膝襪、黑皮鞋）百分之百一致。
2. **無損去背與抗鋸齒**：
   - 採用邊界連通泛洪（Flood Fill）演算法去除外部純白背景，完整保留白襯衫與白裙等內部白色細節。
   - 使用輕微高斯模糊對 Alpha 遮罩邊緣進行抗鋸齒（Anti-aliasing）柔化處理，確保立繪邊緣無生硬白邊或黑線。
3. **高精準對齊**：
   - 裁切並精確縮放至高 `1515px`，與預設立繪頭頂與腳底位置精準對齊，切換表情時無垂直或水平抖動。
   - 完美吻合 `data/personas.json` 中配置的觸碰互動熱區（Touch Zones）。
