# AI 等待回覆 / 思考中動態指示器 (Thinking & Typing Indicator)

## 1. 概述 (Overview)
當使用者與大型語言模型（尤其是 Google Gemini 網頁版或深度推理模型）對話時，從送出訊息到收到第一個 Token 通常需要數秒鐘（包含連線初始化、Prompt 組織、安全性檢測與模型推理）。
為了消除使用者在空白對話框前等待的焦慮感，本功能引入了**現代 AI 對話專用思考指示器 (Thinking Indicator)**，並結合全方位主題自適應與角色立繪系統連動。

---

## 2. 核心特色 (Key Features)

### 2.1 跨主題情境自適應 (Theme-Adaptive Visuals)
不同介面主題下，思考指示器會呈現符合該情境氛圍的圖示、動態與文案：

| 主題風格 | 代表圖示 | 第一階段文案 (0~3.5s) | 第二階段文案 (3.5~8s) | 第三階段文案 (>8s) | 動態圓點與光暈樣式 |
| :--- | :---: | :--- | :--- | :--- | :--- |
| **深色科技 / 預設** | ✨ | 正在思考中... | 深入思考中，即將回覆... | 正在組織語言，請稍候片刻... | 霓虹藍紫跳動光點，搭配呼吸旋轉微光圖示 |
| **LINE 通訊風格** | 💬 | 對方正在輸入... | 正在輸入較長內容... | 即將送出回覆... | 經典原生 LINE 綠圓點跳動，簡潔訊息框 |
| **典藏羊皮紙** | 🖋️ | 執筆沉思中... | 字斟句酌，即將落款... | 墨韻凝思，續寫篇章中... | 古風墨水褐色跳動圓點，羊皮底紙虛線框 |
| **古典書本** | 📖 | 研墨沉思中... | 翻閱古籍，即將撰就... | 博覽群書，字句凝練中... | 古籍深褐色圓點，內嵌柔和古典書頁陰影 |

### 2.2 三階段平滑漸進文案 (Multi-Stage Progressive Hints)
- **0 ~ 3.5 秒**：顯示標準思考/輸入中文案，告知系統已收到請求並在處理。
- **3.5 ~ 8 秒**：若模型處理較長或正在組織深度內容，文字平滑淡出並切換至「深入思考中，即將回覆...」，讓使用者安心。
- **超過 8 秒**：進一步過渡至「正在組織語言，請稍候片刻...」，提供清晰的心理預期。

### 2.3 角色立繪系統連動 (Persona Sprite Integration)
- **發起對話**：一旦使用者按下發送，角色立繪系統自動切換至 **`thinking`（🤔 思考 / 專注）** 姿態與表情徽章。
- **首字抵達**：當伺服器串流吐出第一個內容 Chunk（`data.type === "chunk"`）時，思考指示器立刻平滑淡出，立繪同時還原至常態姿態並啟動對話光暈動畫。
- **情緒解析**：待生成完畢後，若觸發情緒偵測（如開心、害羞、生氣等），系統將接續無縫切換對應表情立繪。

## 3. 程式碼架構與改動清單

### 3.1 樣式檔修改 (`static/css/style.css`)
- **`.thinking-indicator`**：彈性容器，支援毛玻璃（`backdrop-filter: blur(8px)`）與淡入動畫。
- **`.thinking-glow-icon`**：呼吸縮放動畫（`animation: iconPulseBreathe 2s infinite ease-in-out`）。
- **`.thinking-dots .dot`**：三顆跳躍波浪圓點（`animation: bounceDot 1.4s infinite ease-in-out both`），透過負 delay（`-0.32s`, `-0.16s`, `0s`）創造波浪起伏感。
- **跨主題覆寫規則**：
  - `.theme-line .thinking-indicator`
  - `.theme-parchment .thinking-indicator`
  - `.theme-book .thinking-indicator`

### 3.2 邏輯檔修改 (`static/js/app.js`)
- **`renderThinkingIndicator(container)`**：
  - 根據當前 `state.chatTheme` 動態決定圖示與多階段文字。
  - 產生 DOM 並掛載兩組計時器（3.5 秒、8 秒平滑切換）。
  - 回傳 `{ clear: () => void }` 控制器以便在串流抵達時即時取消計時並釋放資源。
- **`handleSend()`**：
  - 插入思考指示器至助理對話框。
  - 呼叫 `setSpriteEmotion("thinking", { temporary: true, duration: 30000 })`。
  - 監聽首批 Chunk 抵達，清除指示器並切換立繪為 `default`。
  - 在 `catch` 與 `finally` 區塊加入防禦性清除與狀態復原。

## 4. 驗證與測試方式
1. 進入首頁 `http://127.0.0.1:8000/`。
2. 切換至任一主題（如深色科技、LINE通訊或古典書本）。
3. 送出對話訊息（如「請寫一首關於月亮的詩」）。
4. 觀察助理對話框內是否立即出現跳動波浪圓點與對應情境文案，且角色立繪同步切換為專注思考姿態。
5. 當第一個文字出現時，思考指示器應平滑消失並開始打字機串流呈現回覆。
