## 二、全表情立繪規格（7 種情緒）

全套立繪儲存於 `data/avatars/coder/{emotion}.png`，皆為規格標準化、高解析度、透明背景的全身立繪（統一畫布尺寸：**680 × 1530**，人物身體基準高度：**1470px**，中軸 X 座標：`X = 330.0`）：

| 表情代碼 | 神情與肢體姿態 | 觸發與情境 |
| :--- | :--- | :--- |
| `default` | 纖手輕扶鏡框，單手夾著機械鍵盤，自信知性微笑 | 日常待命、一般架構諮詢 |
| `happy` | 燦爛開懷笑容，一手比出勝利 V 字或讚，眼中閃耀成就感 | 編譯成功、Bug 完美修復、效能優化達標 |
| `thinking` | 食指輕抵下巴，眼神專注微微向上推敲邏輯 | 演算法分析、系統架構審查、排查瓶頸 |
| `surprised` | 睜大紫眸微張櫻唇，雙手護住鍵盤後退一步 | 突發異常、Production 伺服器報錯 |
| `shy` | 雙頰泛紅，一手輕拉連帽外套兜帽遮掩羞澀笑容 | 受到誇獎、被使用者牽手或觸碰耳機 |
| `angry` | 可愛氣鼓鼓嘟嘴，單手叉腰、舉起鍵盤作勢要敲人 | 遇到垃圾代碼、未經測試 force push 到 main |
| `sad` | 抱著鍵盤稍微欠身，眼神柔和略顯沮喪軟萌 | Memory Leak 難以定位、伺服器環境崩潰 |

## 三、觸碰互動熱區（Touch Zones）配置

熱區設定儲存於 `data/touch_zones/coder.json`，像素級貼合 Kiri 的 680x1530 標準畫布：

1. **頭部 / 挑染馬尾** (`head_touch`)：摸摸頭讚賞，觸發 `happy` 表情。
2. **防藍光眼鏡 / 臉頰** (`glasses_touch`)：扶眼鏡捏捏臉，觸發 `shy` 害羞表情。
3. **發光降噪耳機** (`headphones_touch`)：摘下耳機詢問是否卡關，觸發 `surprised` 表情。
4. **科技帽T / 露指手套** (`hoodie_touch`)：牽手借溫暖暖手，觸發 `happy` 表情。
5. **客製RGB機械鍵盤** (`keyboard_touch`)：試敲手潤線性軸鍵盤，觸發 `happy` 表情。
6. **工裝短裙 / 機能扣帶** (`skirt_touch`)：警告專注看 PR 代碼，觸發 `angry` 生氣表情。
7. **黑透膚過膝長襪** (`stockings_touch`)：害羞解釋是辦公室防冷氣吹，觸發 `shy` 表情。
8. **高筒科技球鞋 / 腳尖** (`sneakers_touch`)：低頭檢查鞋帶與電線，觸發 `thinking` 表情。
