## 一、角色設定與視覺規範

- **角色識別碼 (ID)**：`game_designer`
- **角色名稱**：**Sora 遊戲創意總監**
- **代表圖示 (Avatar)**：🎲
- **外觀特徵**：
  - **髮型與髮色**：活力四射的**日落珊瑚橘（Sunset Coral）高馬尾**，微捲長髮搭配俏皮瀏海與呆毛。

全套立繪儲存於 `data/avatars/game_designer/{emotion}.png`，皆為規格標準化、高解析度、透明背景的全身立繪（統一畫布尺寸：**680 × 1530**，人物身體基準高度：**1470px**，中軸 X 座標：`X = 330.0`）：

| 表情代碼 | 神情與肢體姿態 | 觸發與情境 |
| :--- | :--- | :--- |
| `default` | 瀟灑自信微笑，單手拿掌機，微揚右手展示懸浮全息卡牌 | 日常待命、探討遊戲機制與架構 |
| `happy` | 燦爛開懷笑容，興奮高舉二十面骰「Natural 20 大成功！」 | 數值平衡閉環、核心迴圈驗證大獲成功 |
| `thinking` | 認真凝視，單手輕抵下巴專注推敲掌機螢幕上的數值期望值 | 關卡曲線推導、抽卡機率平衡、戰鬥節奏分析 |
| `surprised` | 睜大琥珀金瞳驚呼「欸？！」，雙手護住掌機微微後仰 | 數值溢出崩潰、出乎意料的邪道玩法 |
| `shy` | 雙頰泛起微紅，眼神輕快飄移，小聲呢喃 | 被誇獎企劃案、被觸碰耳飾或牽手 |

| `sad` | 垂頭喪氣小可憐神情，抱著掌機微扁嘴巴 | 測試反饋卡關、心流中斷、數值填錯崩潰 |

## 三、觸碰互動熱區（Touch Zones）配置

熱區設定儲存於 `data/touch_zones/game_designer.json`，像素級貼合 Sora 的 680x1530 標準畫布：

1. **珊瑚橘高馬尾 / 呆毛** (`hair_touch`)：摸摸頭給予靈感 Buff，觸發 `happy` 表情。
2. **琥珀金瞳 / 軟軟臉頰** (`face_touch`)：捏捏臉抗議心跳數值超標，觸發 `shy` 表情。
3. **開發者名牌 / 獨立遊戲徽章** (`badge_touch`)：輕拍識別證講述展覽血淚史，觸發 `happy` 表情。
4. **立體全息遊戲卡牌** (`card_touch`)：研究 SSR 傳說連攜卡效果，觸發 `happy` 表情。
5. **魔導掌上遊戲機** (`console_touch`)：雙人同屏試玩 Rogue-lite 新詞綴，觸發 `surprised` 表情。
6. **二十面骰 D20 束口袋** (`dice_touch`)：擲骰判定 Natural 20 大成功，觸發 `happy` 表情。
7. **百褶工裝短裙** (`skirt_touch`)：警告防禦等級很高別亂碰，觸發 `angry` 表情。
8. **復古繫帶馬靴 / 長腿** (`boots_touch`)：踏出清脆音效探討空間沉浸感，觸發 `thinking` 表情。
