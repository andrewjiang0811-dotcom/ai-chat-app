# 傲嬌貓娘橫幅形象設計與立繪資產子資料夾分類架構

## 1. 概述 (Overview)
本次更新針對使用者的兩大核心需求進行了深度設計與架構重構：
1. **全新角色立繪形象設計 ——「傲嬌貓娘咪嚕」**：
   - 專為**橫幅配置 (16:9 Landscape Banner)** 設計。
   - 採**「慵懶趴臥」**姿態，搭配微翹的雙腿與空中輕晃的貓尾巴。
   - 全面客製化符合傲嬌性格的觸碰反應台詞與互動熱區。
2. **立繪儲存架構升級（角色專屬子目錄分類）**：
   - 解決以往所有角色立繪與表情圖片全部混雜堆積在 `data/avatars/` 根目錄的問題。
   - 建立獨立角色子資料夾（如 `data/avatars/assistant/`、`data/avatars/tsundere_cat/`），使角色資產井然有序、便於維護與擴展。

## 2. 傲嬌貓娘（咪嚕）橫幅趴臥形象設計

### 2.1 視覺與特徵規範
- **畫布比例**：`16:9` 超寬比例，完美適配橫幅舞台與「上下並排」佈局。
- **慵懶趴臥姿態**：咪嚕趴在柔軟舒適的低平抱枕上，下巴微枕於折疊的雙手手腕處，雙腿在身後自然向上微屈翹起，一條蓬鬆毛茸茸的黑貓尾巴在空中悠閒輕晃。
- **傲嬌神態細節**：
  - 頭頂黑色毛茸茸貓耳（粉色內耳絨毛）。
  - 金色琥珀色貓眼，眼神微向側邊斜睨嬌嗔。
  - 雙腮帶有淡淡羞澀紅暈，微嘟的小嘴露出俏皮的微小貓虎牙。
  - 頸部繫著經典的紅色絲絨頸圈與金色小鈴鐺。
  - 身穿寬鬆舒適的米白色落肩粗針織毛衣與深灰短裙。
- **純綠幕色鍵去背**：
  - 遵循專案《角色立繪生成與去背標準作業規範》（`docs/CHARACTER_SPRITE_GUIDELINES.md`），以純亮綠幕 `#00FF00` 進行生成。
  - 角色身上無任何綠色（米白毛衣、黑貓耳、琥珀金眼、紅頸圈），色鍵演算法 100% 乾淨剔除背景，毛衣細節、貓毛絨毛與肌膚完全飽滿無破損。

## 3. 立繪儲存架構重構（資料夾分類管理）

### 3.1 檔案目錄結構重整
原先所有圖片混在 `data/avatars/` 根目錄，現已升級為按角色 ID 建立專屬子目錄：

```text
data/avatars/
├── assistant/              # 萬能助理專屬立繪庫
│   ├── default.png
│   ├── happy.png
│   ├── shy.png
│   ├── angry.png
│   ├── sad.png
│   ├── surprised.png
│   └── thinking.png
└── tsundere_cat/           # 傲嬌貓娘咪嚕專屬立繪庫
    └── default.png         # 16:9 橫幅趴臥立繪
```

### 3.2 後端與配置檔同步升級
1. **`server.py` 路由升級**：
   - 角色立繪上傳 API（`/api/personas/{persona_id}/avatar` 與 `/api/personas/{persona_id}/emotions/{emotion}`）自動判斷角色資料夾 `os.path.join(AVATARS_DIR, persona_id)`，不存在則自動建立。
   - 上傳後之 URL 規範化為 `/avatars/{persona_id}/{filename}`。
2. **`data/personas.json` 資料庫更新**：
   - 萬能助理全表情路徑全面更新為 `/avatars/assistant/*.png`。
   - 傲嬌貓娘立繪路徑配置為 `/avatars/tsundere_cat/default.png`，並啟用 `full_body` 橫幅展示。

## 4. 驗證與測試
- 於瀏覽器中切換至「傲嬌貓娘」，確認橫幅 16:9 趴臥立繪順暢載入、無變形或穿透。
- 點擊「🖐️ 互動」模式，實測貓耳、鈴鐺、貓尾巴與腳尖熱區，互動對話框貼頂全幅展開，精準顯示傲嬌台詞反饋。
